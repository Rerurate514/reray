# Reray（リレイ） — いつでも作れる記事リレー

**サービスサイト: <https://reray.rerurate.com/>**

「テーマを決めて、枠を配って、記事をつなぐ。」

Reray は、Zenn、Qiita、note、個人ブログなどの外部記事 URL を集め、リレー形式でつなぐ記事リレー（アドベントカレンダー型）の進行管理サービスです。

アドベントカレンダーのように、ひとつのテーマに沿ってみんなで記事を書き、カレンダーの空き枠を埋めていく。その楽しさを、12月に限らず、いつでも・どんなテーマでも・自由な期間で味わえます。

---

## 🌟 主な特徴

1. **いつでも始められる記事リレー**
   1年中いつでも好きなタイミングで、記事リレー（アドベントカレンダー）を始められます。
2. **自由なスケジュール設定**
   開始日と終了日は自由に設定でき、数日間の短期リレーから30日間の長期チャレンジまで幅広くカバーします。枠の自動生成は「毎日（Daily）」と「平日のみ（Weekdays）」に対応しています。
3. **スムーズな募集とシェア（Slack / Discord / X）**
   Slack、Discord、X（旧Twitter）に合わせた募集メッセージをワンクリックでコピーできます。参加者集めやコミュニティへの共有を後押しします。
4. **いろいろなプラットフォームの記事をまとめて登録**
   Zenn、Qiita、note、はてなブログ、個人ブログなど、URLがあればどのプラットフォームの記事でも登録できます。
5. **公開範囲を選べる**
   トップページの開催中一覧に載せる「公開」と、URLを知っているメンバーだけが楽しめる「限定共有（プライベート）」を選べます。

---

## 🚀 使い方ガイド

### 1. リレー（カレンダー）を作る
1. ログイン後、ヘッダーの「作成（New）」ページへ進みます。
2. リレーの**タイトル**、**説明**、**関連するタグ**を入力します。
3. リレーの**開始日**と**終了日**、枠を生成する頻度（**毎日**または**平日のみ**）を設定します。
4. 公開範囲（**公開**または**限定共有**）を選び、「作成する」を押すと、投稿枠（スロット）が自動生成されたカレンダーが完成します。

### 2. 参加者を募集する
- カレンダー詳細ページの「参加者を招待する（Share）」セクションから、Slack、Discord、X（旧Twitter）用の招待テキストをワンクリックでコピーし、コミュニティやSNSにシェアしましょう。

### 3. スロット（枠）に参加して記事を書く
1. 参加したいリレーのカレンダーを開き、空いている日付（スロット）の「参加する」を押します。
2. 担当日に向けて記事を執筆します。
3. 書いた記事のURLとタイトルを、割り当てられたスロットに登録します。
4. 登録した記事はカレンダー上に自動でリンクとして反映され、みんなの記事がつながっていきます。
